During the development of this meal picker application, I encountered several key challenges. In commit 072c2c7fb7881c4a44f393e5c54f58dfc1098932, I spent a lot of time troubleshooting the syntax to bring information in from the API. And when I did bring information into my webapp, it was incomplete. I added many console.log statements throughout my app.post function. It was very time consuming to work through this as I had to restart the server with each and every iteration. Another troubling situation was adding functionality of displaying all retrieved results, in git eec91d638fb598adee5423169bd4496e98b7c7a9. It was my first time using math operations to build a strings containing the API results. The forEach operation allowed me to present the meal results one by one. Formatting took a lot of trial and error, but was easy to configure.
